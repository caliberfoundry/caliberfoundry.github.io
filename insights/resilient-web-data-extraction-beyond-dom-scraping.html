Combining supplier catalogs without losing product variants

Align CSV columns, normalize tracking URLs and remove duplicate rows across supplier files.

What makes two rows the same?

A supplier can use one product URL for several SKUs. StealthFlow removes tracking parameters from the product URL, then compares all the fields. Two copies of the same product row collapse into one. A different size, SKU or price remains a separate record.

Merge two exports

Use the browser to clean one local file. For multiple suppliers, select their exports in the batch workbench. The batch service accepts the same column names in different orders. It rejects a file with missing columns so a price cannot silently land under a SKU heading.

File A
sku,url
S,https://shop.example/item?utm_source=feed

File B
url,sku
https://shop.example/item,S
https://shop.example/item,L

These three rows produce two records: S and L. The interactive workbench includes a preview and a downloadable CSV.

Call the batch API

The following example reads your files as UTF-8 and posts their contents to Caliber Foundry. The response contains the output headers, rows and counts. The service processes up to 12 catalogs, 10,000 input rows and 512 KiB of JSON per request, in memory. URLs inside the files are treated as text.

python3 - first.csv second.csv <<'PYTHON' | curl --fail-with-body -sS \
  -H 'Content-Type: application/json' --data-binary @- \
  https://api.caliberfoundry.com/portfolio/v1/stealthflow/catalogs
import json, pathlib, sys
print(json.dumps({"catalogs": [pathlib.Path(p).read_text(encoding="utf-8-sig")
                              for p in sys.argv[1:]]}))
