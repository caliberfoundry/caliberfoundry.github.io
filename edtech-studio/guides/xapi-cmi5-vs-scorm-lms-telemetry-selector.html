Three Architectural Differences Between SCORM 1.2, xAPI, and cmi5

  • SCORM 1.2 = Universal Zero-Infra Baseline: Runs inside a same-origin LMS frameset via window.API; zero LRS servers or OAuth tokens required.
  • Pure xAPI (IEEE 9274.1.1) Lacks LMS Packaging Rules: Raw xAPI defines JSON statements (actor, verb, object, result) over REST, but does not define how an LMS launches a course or marks an assignment complete.
  • cmi5 Bridges LMS Launch + xAPI: ADL's cmi5 profile adds an XML course structure (cmi5.xml), launch URL token handoff, and deterministic moveOn completion rules on top of xAPI.
