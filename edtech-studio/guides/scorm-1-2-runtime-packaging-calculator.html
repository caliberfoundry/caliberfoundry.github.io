Key Verified SCORM 1.2 Engineering Rules

  • 4,096-Character Ceiling: SCORM 1.2 defines cmi.suspend_data with an SPM of 4,096 ASCII characters (unlike SCORM 2004 3rd/4th Edition's 64,000-character limit).
  • String-Typed API Calls: Every window.API method (LMSInitialize(""), LMSCommit(""), LMSFinish("")) requires an empty-string argument ""—passing null or omitting it triggers Error 201 on strict adapters.
  • Single Vocabulary Element: Unlike SCORM 2004 (which splits completion and success), SCORM 1.2 merges both into cmi.core.lesson_status (passed, completed, failed, incomplete, browsed, not attempted).

Technical Drill-Down 01 — Minimal Zero-Dependency SCORM 1.2 API Discovery Snippet

A compliant SCORM 1.2 SCO walks parent and opener frames (up to 7 levels) to locate window.API, initializes with "", and guards offline/standalone preview gracefully:

function findScorm12Api(win) {
  var depth = 0;
  while (win && !win.API && win.parent && win.parent !== win && depth < 7) {
    depth += 1;
    win = win.parent;
  }
  return (win && win.API) || (window.opener && window.opener.API) || null;
}
