Three Non-Negotiable ISO 14289-1 (PDF/UA-1) Structural Requirements

  • Real Content vs. Artifacts (CP 01): Running headers, page numbers, and decorative rules must be marked as /Artifact so screen readers do not interrupt sentences mid-page.
  • Viewer Preferences & Language (CP 06, CP 11): Every compliant PDF must set /ViewerPreferences << /DisplayDocTitle true >>, non-empty dc:title, and a valid BCP-47 /Lang (en-US) key.
  • Automated Checkers Cannot Verify Meaning: PAC / VeraPDF catch machine-checkable syntax errors, whereas logical reading order (CP 09) and accurate STEM alt-text require human verification.
