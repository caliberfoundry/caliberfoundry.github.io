What makes the comparison fair?

Count every paid call

Add the cost of first attempts, retries and reviews on both sides. A failed task still contributes to spend. Only tasks accepted by the independent reviewer count in the denominator.

Check the same tasks and criteria

Compare the same work and keep the review standard fixed. If a task that passed before now fails, a lower bill alone cannot justify the change.

Identify the source of the price

Use actual charges where available. Token counts priced from a rate card give an estimate. An unpriced subscription run cannot establish a dollar saving.
