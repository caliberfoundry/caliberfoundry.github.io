Technical drill-downs

Technical Drill-Down 01Supported CSV Schemas & Zero-Upload Browser Isolation

FinOpsGuard ingests files through the local HTML5 FileReader API with strict Content-Security-Policy enforcement. Billing line items, account IDs, and internal resource ARNs never leave the analyst’s workstation.

Out of the box, the schema detector maps AWS Cost & Usage Report columns (lineItem/ProductCode, lineItem/UsageType, lineItem/UnblendedCost, pricing/term), FinOps Foundation FOCUS 1.0 columns (ProviderName, ServiceName, ChargeCategory, CommitmentDiscountStatus, BilledCost, EffectiveCost), and OpenAI / Anthropic usage exports (input_tokens, input_cached_tokens, output_tokens, batch, cost_usd).

Technical Drill-Down 02Fact-vs-Estimate Separation & Explicit Formula Disclosures

Traditional FinOps dashboards blend historical invoice totals with speculative vendor savings, eroding credibility with CFOs and staff engineers. FinOpsGuard enforces a hard two-column separation:

Confirmed CSV Facts represent exact floating-point cent-rounded sums of imported rows. Modeled Savings Estimates apply transparent user-editable coefficients (e.g., 24% 1-year No-Upfront Compute Savings Plan net discount on steady-state On-Demand instances, 50% Batch API discount on eligible non-interactive token workloads, and cached-token read delta) paired with a mandatory pre-implementation engineering check.
