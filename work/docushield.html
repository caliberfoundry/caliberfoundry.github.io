Review PDFs before publication

For accessibility specialists and document teams checking recurring publications. Keep the report with each revised PDF so a reviewer can follow up on the findings.

1. Audit a PDF

Upload a PDF up to 25 MB. The studio runs veraPDF against PDF/UA-1 and lists machine-detectable issues, including missing tags, metadata and font information.

2. Review and repair

Review images and add descriptions where needed. Auto mode keeps complex layouts in place and can rebuild eligible plain-text pages. Some issues may remain.

3. Check the revised file

Download the PDF and JSON report. Compare failed rules before and after repair, then check the reading order, table headers, image descriptions and contrast yourself.
